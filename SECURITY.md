# Security policy

## Supported versions

No version is implemented, published, or supported. This planning repository
must not be used as an OAuth authorization server or security dependency.

## Reporting

Report suspected vulnerabilities through a private
[GitHub security advisory](https://github.com/faustbrian/go-oauth-server/security/advisories/new).
Include the affected revision, a minimal reproducer, the expected security
invariant, and the observed impact. Do not include real authorization codes,
tokens, client secrets, signing keys, user records, or production requests.

## Planned boundary

Future implementation must satisfy the threat model and release blockers in
[docs/security.md](docs/security.md). Planning text and passing metadata checks
are not implementation or security evidence.
